Zdravé ucho

Zásady ochrany soukromí

Platné od 13. 11. 2026. Provozovatel: Milan Marek. Kontakt: stránka podpory.

Shrnutí

Zdravé ucho neshromažďuje žádné osobní údaje. Všechna data zůstávají ve tvém iPhonu.

Co appka nedělá

  • Nemá uživatelské účty ani přihlášení.
  • Nemá server a neodesílá žádná data mimo zařízení.
  • Neobsahuje analytiku, reklamu ani kód třetích stran.
  • Nesleduje tě napříč appkami a weby.

S čím appka pracuje v telefonu

Mikrofon. Appka z něj průběžně počítá hlasitost okolí v decibelech. Zvuk nenahrává, neukládá ani neodesílá. Při měření místa běží mikrofon i se zamčeným telefonem, dokud měření neukončíš.

Aplikace Zdraví. S tvým svolením appka čte hlasitost sluchátek a uložené audiogramy, aby je zobrazila a spočítala týdenní zátěž. Do Zdraví nic nezapisuje. Data ze Zdraví nepoužívá k reklamě ani je nikomu nepředává.

Výsledky testů a měření. Výsledky testů sluchu, testů řeči v šumu, měření míst a tvoje nastavení se ukládají jen do úložiště appky v telefonu.

Oznámení. Pokud si je zapneš, appka posílá místní upozornění přímo z telefonu.

Sdílení

Data opustí telefon jen tehdy, když sám vytvoříš PDF a pošleš ho, komu chceš.

Smazání dat

Jednotlivé výsledky smažeš v appce. Smazáním appky smažeš všechna její data. Svolení ke Zdraví a mikrofonu odvoláš v Nastavení iPhonu.

Děti

Appka není určená dětem mladším 13 let a neshromažďuje o nich žádné údaje.

Tento web

Stránky běží na GitHub Pages. GitHub jako provozovatel hostingu zpracovává technické údaje o návštěvě, například IP adresu. Web sám nepoužívá cookies ani analytiku.
